# Roblox Football Game

Clean Roblox football project built from scratch.

## Development

- Roblox Studio for environment and asset placement
- Rojo for live source synchronization
- Luau for gameplay systems

## Initial scope

1. Clean third-person player controller
2. Football possession and carrying
3. QB passing and ball physics
4. Catching and interceptions
5. Field boundaries, downs, and scoring
6. Teams and match flow
7. HUD and scoreboard
8. Stadium integration

No legacy shooter runtime or donor game code is included.
